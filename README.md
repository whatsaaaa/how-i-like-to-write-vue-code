# how-i-like-to-write-vue-code

[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](./LICENSE)

A Nuxt app that shows how I like to write Vue code

## Use it

Run it with `pnpm dev`.

## Working on it

You need Node.js (22.18 or later on 22, or 24.12 or later) and [pnpm](https://pnpm.io/installation), which switches itself to the version `packageManager` names in `package.json`.

```sh
pnpm install
```

| Command           | What it does                                         |
| ----------------- | ---------------------------------------------------- |
| `pnpm dev`        | Starts the app on a local server                     |
| `pnpm build`      | Builds the app into `.output/`                       |
| `pnpm test`       | Runs the unit tests                                  |
| `pnpm lint`       | Checks the code, the stylesheets, fixing what it can |
| `pnpm type-check` | Type-checks everything                               |
| `pnpm format`     | Formats everything                                   |
